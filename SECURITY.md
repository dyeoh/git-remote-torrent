# Security Policy

git-remote-torrent verifies signatures on refs that come from untrusted peers, so
security bugs matter. Please **don't open a public issue** for them.

Report them privately through
[GitHub Security Advisories](https://github.com/dyeoh/git-remote-torrent/security/advisories/new).
You'll get an acknowledgement within 7 days.

Supported versions: the latest 0.x release only, until 1.0.

The threat model is in [docs/explanation/threat-model.md](docs/explanation/threat-model.md).
