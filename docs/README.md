# git-remote-torrent documentation

These docs follow the [Diátaxis](https://diataxis.fr/) structure:

- **Tutorials** are lessons that take you through a task from start to finish.
- **How-to guides** are recipes for specific goals.
- **Reference** pages hold exact specifications: URL syntax, manifest format, CLI and
  versioning.
- **Explanation** pages cover design, architecture and the threat model.

Design decisions are recorded as [ADRs](adr/README.md).
