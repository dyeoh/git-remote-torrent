# Tutorial: your first immortal repo

> Placeholder. Written as part of the 0.2 release ("kill-switch" demo).

1. Push a repo to any hosted remote, for example `https://github.com/you/project.git`.
2. `git torrent init && git torrent seed`
3. Delete the hosted repository.
4. `git clone torrent::https://github.com/you/project.git` from another machine still works.
